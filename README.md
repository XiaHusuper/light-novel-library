# 轻小说文库

独立 Android 阅读 App。在线正文和插图按需读取，普通阅读不自动缓存；可手动缓存章节、分卷或整本；支持本地 EPUB/TXT、书架、目录、阅读进度与阅读设置。

仓库：[XiaHusuper/light-novel-library](https://github.com/XiaHusuper/light-novel-library) · [发布与更新日志](https://github.com/XiaHusuper/light-novel-library/releases)。私人仓库需要 GitHub 账号访问权限。

## 已实现

- 启动默认进入书架；底栏为发现、书架、推荐、本地、我的。
- 搜索区提供书名、作者、标签三个明确入口，默认书名；标签入口支持多个词并与多选分类联动。发现页负责搜索与榜单；“为你推荐”为独立栏目，不占用搜索或榜单的模式。
- 在线作者名可在列表及详情点击，进入作者全部作品，兼容有分页和一次返回全部结果的接口。
- 列表接近底部自动加载下一页；保留已有卡片与封面，不要求逐次点击“再看一些”。
- 首批封面优先请求，后续封面提前约两屏加载；封面仅有上限的内存复用，不保存离线图片文件。
- 全部 13 种来源榜单：总/月/周/日点击、总/月/周/日推荐、最新入库、最新更新、总收藏、字数、完结小说。
- 移植 Novel Recommendation 的分卷与目录规则：中文/数字卷号、上下册、正篇/外传/Web、同作品多文件合并、编号短篇集排序与 TXT 重复目录清理。
- EPUB 2 NCX 与 EPUB 3 嵌套目录、同文件页内锚点分章、跨文件续文；按实际条目读取。
- 本地详情右上角“调整目录”：分别移动分类内卷册、卷内章节；取消丢弃草稿，保存持久生效，支持恢复自动顺序。按稳定章节键保留阅读位置。
- 文件多选和系统文件夹导入，保留原文件读取授权，每次最多 200 个文件、8 层目录。
- 五组 49 标签、多选“同时包含/包含任一”。首次检索先读取少量关键词候选并严格核对真实标签，同时补建全库书目索引；可暂停、续传、显示进度；完整索引后才给出“全库无匹配”的结论。可用 `#标签` 搜索，标签面板也可查找标签。
- 阅读偏好、喜欢/不感兴趣与独立标签推荐。
- 阅读历史与主动收藏分开；浏览、阅读不会自动加入收藏书架。旧版未收藏项迁入历史，阅读位置保留。
- 阅读画像展示标签兴趣及来源作品、浏览/阅读/收藏/喜欢分数，可清空浏览与阅读学习。
- 底栏“我的”集中登录、浏览记录、阅读位置、阅读画像、离线缓存与全局设置；新增“关于”可查看安装版本、检查 GitHub 最新发布、阅读更新日志及离线许可证／致谢。
- 书签分类可直接选择已有分类或未分类，也可选择“新建分类”后输入新名称；访客也可使用记录与画像。
- “我的”登录区和原生登录弹窗角落提供“注册 Wenku8 账号”，仅用外部系统浏览器打开 `https://www.wenku8.net/register.php`，不调用注册 API，不在 App 内加载注册页。
- 默认使用原生账号／邮箱及密码登录，通过既有账号接口建立会话、验证资料和读取云书架；收藏增删后重新读回确认。0.4.3 已移除被来源封禁的网页登录入口。
- 每本在线小说详情页的固定“缓存”入口可手动保存章节、分卷或整本，可包含插图和封面；默认上限 200 MiB，可调 50–1024 MiB，支持停止、重复任务复用和清理。
- 详情、简介、目录独立并行加载，目录就绪即可开始阅读。
- 在线正文到达后分批显示，不等待正文写盘；图片仅在接近可见区域时加载。
- 阅读默认隐藏书名、返回、设置和底部工具栏，仅显示章节名、本章页数和进度；中间区域轻点以 240ms 动画展开／收起，章节信息同步下移，正文不重新分页。设置按钮为齿轮。
- 可仅在阅读时隐藏系统状态图标，原位置保留本机时间和电量，退出阅读恢复；仍可按系统手势临时呼出系统栏。
- 长按选中文字，Android 浮动菜单为复制、书签、插图；保留系统文字选择手柄。
- “我的 → 书签”保存摘录、作品和章节名，支持分类、删除、按稳定位置回原文；无需登录，不参与账号同步。
- 本卷插图页面自动汇集当前分类、当前卷的图片，去重，按原目录排列；失败章节可重试，全部查完确实没有图片时提示未找到。仅临时读取，不写离线缓存。
- 首页和“我的”用户名左侧、Android 安装图标采用同一套书页与星光设计；继续阅读卡片展示真实封面。
- 滚动阅读、左右跟手滑动与松手吸附；轻点左右 20% 边缘直接切页，无动画。支持回弹、手势取消、纵向误触排除和减少动态效果。
- 字号、行距、衬线/无衬线、纸白/暖色/夜间主题。
- 插图独立查看，双指缩放、放大后拖动、双击缩放。
- 行内注解小图保持约一字高；保留 EPUB 行内及内部样式表的安全文字颜色，语义脚注显示红色；SVG 包装插图提取实际图片。
- 续读保存具体文本／图片锚点与少量图片尺寸，图片逐个加载时维持位置；不保存正文或图片字节。
- 推荐排除本机收藏、账号书架和能按作品名／作者精确匹配的本地作品。
- 通过 Android 系统文件选择器批量导入 EPUB/TXT。
- EPUB 保留目录、基本排版、注音和插图，按 ZIP 条目读取，不解压整本。
- TXT 识别 UTF-8、UTF-16、GB18030，并识别章节；无章节标题时自动分节。
- 书架、目录、阅读进度和设置保留，退出和重启后可续读。

## 存储约定

普通在线阅读不会将整章正文或插图写入离线存储。主动创建的书签会在独立本机存储中保存最多 4000 字选中摘录、书目元数据和稳定位置，最多 1000 条 / 2 MiB；删除、清空画像或退出账号不会混同修改其他记录。用户明确选择“缓存阅读”后，所选章节以 JSON 文本和图片文件保存到应用私有 `files/offline/`，不下载或生成 EPUB。优先读取已保存的章节和插图，未缓存的章节仍按需联网。缓存目录和书目元数据受同一空间上限约束；满额时停止继续写入，不自动删除用户手动保留的书。清理入口在“我的 → 离线缓存”，卸载应用会删除这些文件。

阅读器 WebView 的 DOM 存储禁用，网络响应设为不保存。默认账号登录使用原生表单，密码不进入阅读器 JavaScript，提交后立即清空输入框，不保存密码。账号会话用 Android Keystore AES-GCM 加密保存。0.4.3 不再创建官网账号 WebView，不提供网页登录桥接操作。旧网页账号快照仍保留书架，但需用账号／密码重新登录；官网 Cookie 不转换为 API 会话，也不交给小说图片请求。密码不进入应用状态文件。

运行时存在必要的临时内存和 Android/WebView 自身的基础运行文件，不把“无正文缓存”表述为整个应用占用恒为零。全库书目索引最多 4 MiB / 10000 本，按用户首次标签检索建立，只保存书目；完成后复用，超过 7 天可自动重建，也可手动更新。目录元数据最多 24 本，本机收藏最多 300 本，历史和进度最多 200 本，行为画像最多 150 本且按时间清理；封面内存最多 96 张 / 6 MiB。阅读器打开期间最多复用最近 2 章 / 6 MiB 正文字符串，仅在内存，关闭阅读器释放；不预取新章、不自动落盘。程序不写滚动日志。

本地手动目录最多保存 100 部作品 / 1 MiB；仅记录源文件和章节键，不改写 EPUB/TXT。新导入内容追加到对应分类或卷册，已有手动次序保持。

本地导入优先保存原文件的长期读取授权。提供方不支持长期授权时，仅在用户主动导入时保存一份原文件副本。移除本地书籍会清理应用持有的副本与元数据，保留用户原文件。原文件被移动或授权失效时，需要重新导入。

## 兼容性

- Android 8.0 / API 26 及以上。
- 包含 ARM64（手机）和 x86_64（模拟器）原生运行库，不包含 32 位 ARM。
- 独立包名：`com.xiahu.reader`，不会覆盖其他阅读器。
- 需要可访问来源服务的网络；本地书籍可离线阅读。App 不依赖电脑保持开机或本地 Python 服务。
- 当前版本：0.7.1。包名和签名与旧版一致，可覆盖升级。主动收藏、本地文件授权和阅读位置保留；旧版混入的未收藏书目移到历史。仅申请联网权限，导入使用系统文件选择器，无需全盘存储权限。

## 实现

Java Android Activity、本地 WebView 阅读界面、原生网络与文件读取。默认账号操作使用原生网络及加密会话；0.4.3 已移除备用网页登录入口及对应桥接触发。阅读器仍使用本地界面和原生请求。

在线协议基于已验证的客户端请求格式，通过原样保留的 `TokenManager` JNI 组件生成请求参数，再访问 MewX 中继。书目内容来源为 Wenku8，图片按正文中返回的实际 URL 获取。来源若未提供内容，展示错误，不另设网页绕过或批量采集流程。

本工程没有复用原 Flutter 项目的界面源码，参考了其功能组织与阅读体验。原生第三方组件的来源和边界见 [THIRD_PARTY.md](THIRD_PARTY.md)。

算法来源、榜单参数、阅读画像和同步边界见 [ALGORITHMS.md](ALGORITHMS.md)。推荐候选来自已加载榜单和书架，候选内存上限 300，随用户浏览获取分页。推荐结合标签余弦相似度、主动偏好和阅读学习，并考虑题材均衡、多样性及探索位；简介 TF-IDF 和中文分词尚未接入。只有主动收藏和账号书架成员计收藏分，阅读历史不算收藏。

## 构建

推荐用 Android Studio 打开本目录，使用 JDK 17、Android SDK 35、SDK Build Tools 34.0.0。Gradle 配置为 AGP 8.6.1 / Gradle 8.7。

Gradle 的 release 构建未预置签名，请使用 Android Studio 的签名向导或下方脚本。发行 APK 的私有签名密钥不随源码包分发。

也可使用官方 SDK 工具直接构建，无需 Gradle 守护进程：

```powershell
$env:JAVA_HOME = '你的 JDK 17 路径'
$env:ANDROID_HOME = '你的 Android SDK 路径'
python tools/build_apk.py
```

脚本会在 `dist/` 生成签名 APK，在 `.signing/` 创建并保留本机签名密钥。该目录不得加入源码分发包；后续覆盖升级必须保留同一签名密钥。`--debug` 可生成仅用于开发验证的可调试 APK。

## 同步与记录边界

“历史记录”分为浏览记录和阅读位置。打开过详情但未阅读的作品也记浏览时间；开始阅读后保存章节与章内位置。两种记录无需登录，均只保留本机。阅读画像也只保留本机。

按本次最终要求，账号仅同步 Wenku8 书架成员：官网收藏读入 App，App 内收藏或移出在线作品写回官网。旧本机收藏通过“我的”手动上传。浏览历史、阅读位置和书签不导入、不上传，账号同步不会修改本机进度。每次写回后重新读取书架确认，不以收到一个网页就认定成功。

## 并发范围

阅读接口全局最多 3 个在途请求，包括手动缓存。缓存本身只有一个任务，章节串行、请求间短暂停顿；普通界面的全库标签索引自身最多 2 个并发元数据请求，仍共用上述 3 请求总上限。封面最多 5、正文插图最多 2，图片使用其自身地址，官网账号同步走官网。首次阅读需要的请求总数、返回字节数、服务端处理成本与峰值并发是不同指标，不能由线程数算出服务器占用倍数。核对的参考客户端 0.4.8 普通任务池为 4，并有其他路由和缓存，因此 `3/4` 也不能当作实际中继负载比例。

## 标签检索与更新

来源目前没有接受本客户端标签参数的搜索入口，因此不能把当前榜单已加载的十几本书当成全库。标签检索逐页读取“最新入库”的书目元数据，保存精简索引，显示已查页数及匹配数，支持暂停和重启续传。第一次需要等待索引建立，稀有标签在后面页面时结果会自动出现，不需要反复点刷新。正在检索、暂停、失败、完整无匹配是不同状态。完成后再选标签不重复扫描，7 天后或用户点更新时重建。

全库标签结果按更新日期排序，此时榜单选择暂时禁用，避免暗示结果保留未读取榜单的名次。标签与输入的书名／作者关键词可取交集；点作者名会清掉标签条件，读取该作者的作品。推荐、发现中的查询分别保留结果；普通书名搜索永远使用书名接口，不向服务器提交 `sort=recommend`。

翻页手势参照原网页阅读器：手指横移时移动已有分页，松开后约 220ms 归位或翻一页，点边缘不动画。跨章先显示章节提示，确认翻页后才取正文，不为了动画自动预取相邻章节或写盘。原 D 盘网页工程仅作为只读参考，未修改。


0.6.0：通用阅读设置移除“缓存正在读的分卷”，下载从每部在线小说详情进入；“我的 → 离线缓存”负责管理清理。详情缓存默认使用该书自己的上次阅读卷，未读则第一卷，切换书目不会误用另一部作品。系统状态栏通过 Android WindowInsetsController（旧系统使用对应兼容标志）控制，时间／电量使用本机状态，不增加联网请求。参见 [Android 官方沉浸模式说明](https://developer.android.com/develop/ui/views/layout/immersive)。

书签保存在独立 `reader_bookmarks` 本机偏好存储，不能同步到 Wenku8；摘录是用户主动保存的内容，不是默认正文缓存。本卷插图查询最多两章并行复用现有读取协议，当前章已有临时内容时复用，关闭页面停止排后续请求。每个 EPUB 片段遵守 from/to 边界，避免同一 XHTML 中的其他卷混入。原文件没有修改，未新建 EPUB。
